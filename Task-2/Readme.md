📈 Smart Stock Portfolio Tracker

🚀 Project Overview

The Smart Stock Portfolio Tracker is a beginner-friendly Python project developed as part of the CodeAlpha Python Programming Internship – Task 2.

This application allows users to:

View available stocks and their prices
Purchase one or multiple stocks
Calculate total investment value
Save portfolio details into a text file automatically


🛠️ Technologies Used
Python
Dictionary
Conditional Statements
Loops
File Handling


✨ Features

✅ Displays available stock prices
✅ Accepts user stock inputs
✅ Supports multiple stock purchases
✅ Calculates total investment value
✅ Saves portfolio summary into portfolio.txt
✅ Beginner-friendly Python logic


📂 Project Structure

├── portfolio_tracker.py

▶️ How to Run the Project
Install Python on your system
Save the program as:
portfolio_tracker.py
Open terminal or command prompt
Run the program:
python portfolio_tracker.py
