# CodeAlpha Python Programming Internship - Task 1

## Hangman Game in Python

This project is a simple **Hangman Game** developed using Python as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Description

Hangman is a word guessing game where the player tries to guess the hidden word one letter at a time.  
The player has limited chances to make wrong guesses before the game ends.

This project demonstrates:
- Python basics
- Loops and conditions
- Functions
- Lists and sets
- Random module usage
- User input handling

---

## 🚀 Features

- Random word selection
- Hangman visual display
- Tracks guessed letters
- Prevents duplicate guesses
- Win/Lose conditions
- User-friendly interface

---

## 🛠️ Technologies Used

- Python 3
- Random Module
